# Die Heilerin vom Scheiterhaufen

Roman von Stephan Hink — deutsch, und in dänischer Fassung als *Heksen på bålet*.

Das Missionsschiff *Semmelweis* ist auf dem Weg zum Mars, als ein Pilz aus dem eigenen
Gewächshaus die halbe Besatzung tötet. Die einzige dokumentierte Heilung dieser Krankheit
steht in einer Hexenprozessakte aus Trier, Oktober 1589 — dort als Beweis der Schuld.
Drei Menschen und vierzehn Kilogramm künstlicher Verstand reisen in eine Stadt, die gerade
Frauen verbrennt. Sie haben elf Tage.
